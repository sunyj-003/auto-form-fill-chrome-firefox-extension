# 持续自动填充功能 - 验收标准 (V2)

## 功能描述
当开启"持续自动填充"开关后，扩展会自动检测并填充页面中动态加载的表单内容，包括：
- 点击下一步/提交后出现的新表单
- 页面导航后出现的新表单
- AJAX 动态加载的表单元素

## 验收标准

### 0. 原有功能不被破坏 (CRITICAL)
- [ ] 原生 HTML 表单填充正常
- [ ] Element Plus 表单填充稳定 (100%)
- [ ] Material UI 表单填充正常
- [ ] jQuery Select2 下拉框填充正常
- [ ] 原生 select 下拉框填充正常
- [ ] Ant Design (原生 input) 表单填充正常

### 1. 设置开关
- [ ] 在设置页面添加"持续自动填充"开关
- [ ] 开关状态保存在 chrome.storage.sync 中
- [ ] 开关默认为关闭状态
- [ ] 开关有清晰的 UI 标识和提示文字

### 2. DOM 变化监听
- [ ] 使用 MutationObserver 监听页面 DOM 变化
- [ ] 检测到新增表单元素时自动填充
- [ ] 对新增元素进行去重，避免重复填充

### 3. 页面导航监听
- [ ] 监听 popstate 事件（浏览器后退/前进）
- [ ] 监听 pushState/replaceState（单页应用导航）
- [ ] 页面 URL 变化时检测并填充新表单

### 4. 填充逻辑
- [ ] 新元素填充时保持原有的字段识别逻辑
- [ ] 已填充过的元素不再重复填充
- [ ] 填充行为与手动触发一致

### 5. 性能与稳定性
- [ ] MutationObserver 使用合适的配置（subtree, childList）
- [ ] 有防抖机制，避免频繁触发
- [ ] 开关关闭时正确清理监听器

### 6. 测试稳定性要求
- [ ] 所有 E2E 测试必须 100% 稳定通过
- [ ] 不允许随机失败
- [ ] 每次运行结果一致

## 回归测试要求

在开发新功能时，必须确保以下测试全部通过：

```
npx playwright test tests/e2e/form-test.spec.js
```

**必须通过的测试：**
- ✅ 原生 HTML 表单
- ✅ Element Plus 表单 (稳定 100%)
- ✅ 原生 select 下拉框
- ✅ Ant Design (原生 input)
- ✅ jQuery Select2
- ✅ Material UI

## 测试场景

### 场景 1: 动态加载表单
1. 页面初始有一个表单
2. 点击"下一步"按钮
3. AJAX 加载新的表单区域
4. **预期**: 新表单自动被填充

### 场景 2: 页面导航
1. 填写表单 A，点击提交
2. 页面跳转到结果页 B（有表单）
3. **预期**: 新页面表单自动被填充

### 场景 3: 开关控制
1. 关闭"持续自动填充"开关
2. 点击下一步加载新表单
3. **预期**: 新表单不会被填充

### 场景 4: 多页向导
1. 开启开关
2. 完成第 1 步 → 自动填充第 2 步
3. 完成第 2 步 → 自动填充第 3 步
4. **预期**: 每一步的新表单都被自动填充

## 验收流程

1. **先运行回归测试**: 确保原有功能不被破坏
2. **再运行新功能测试**: 验证持续自动填充
3. **稳定性验证**: 运行至少 10 次，确保无随机失败

```bash
# 回归测试 (必须 100% 通过)
npx playwright test tests/e2e/form-test.spec.js --reporter=line

# 新功能测试
npx playwright test tests/e2e/auto-fill.spec.js --reporter=line
```

## 问题追踪

如果测试失败：
1. 检查是否是回归问题（原有功能）
2. 检查是否是随机问题（需要修复代码）
3. 检查是否是测试环境问题（CDN 加载等）
